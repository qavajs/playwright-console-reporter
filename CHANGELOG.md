# Changelog

## [0.1.0] - 2026-04-23

### Added
- Initial release
- Cucumber-style console reporter for Playwright Test
- Per-step pass/fail/skip indicators with ANSI colour output
- `showOutput` option to print captured stdout/stderr beneath each step
- `prefix` option to customise the label shown before each test name (default: `Scenario`)
- Summary table with scenario and step counts on run completion
